# Project Vanguard — Unity 6 Multiplayer Tactical FPS Framework

A production-style, modular first-person shooter foundation for **Unity 6 LTS** built on the modern package stack:

| Area | Technology |
|---|---|
| Rendering | Universal Render Pipeline 17 (URP) |
| Input | Input System 1.20 (code-defined actions, keyboard/mouse + gamepad) |
| Navigation | AI Navigation 2.0 (`NavMeshSurface`, `NavMeshLink`, `NavMeshModifier`) |
| Networking | Netcode for GameObjects 2.13 + Unity Transport (client-server / host, server authority) |
| UI | uGUI 2.0 (HUD and menus built procedurally from a theme asset) |

Everything (scenes, prefabs, terrain map, materials, data assets, NavMesh) is generated by **one editor command**, `FPS > Build Everything`, so the repository holds only source code and the project opens without broken references.

> **Browser version:** [`web/dist/VANGUARD.html`](web/dist/VANGUARD.html) is a playable HTML5/Three.js version of the game in **one file**. Download it and double-click it. It has offline single-player against bots, and online multiplayer where one player hosts in their browser and friends join with a room code (no server needed). There are six modes (TDM, Domination, FFA, Gun Game, Elimination, Horde) and three maps. It plays with keyboard and mouse or with on-screen touch controls on phones and tablets. It also has a CoD-style menu, Ranked with a rank after every game, adaptive bots, 50 weapon camos and 12 outfits, progress saved in cookies and browser storage, realistic gun physics (bullet travel time and drop, wall penetration, recoil patterns, sway and hold breath), and friends: friend codes, online status, friend profiles, squads that play Ranked and team modes together, and rated Showdown 1v1s. See [`web/README.md`](web/README.md).

## Features

- **Player controller**: walk, sprint, jump (coyote time and jump buffering), crouch with ceiling check, air control, slopes and steps, ground snapping, fall damage. It is deterministic so it can be predicted.
- **FPS camera**: mouse look with configurable smoothing, gamepad response curve, recoil (recoverable plus permanent climb), ADS and sprint FOV, head bob, landing dip, damage shake, death cam.
- **Weapons**: ScriptableObject-driven (`WeaponData`). Semi, auto, burst and multi-pellet fire, reload (tactical and empty), ADS, switching (1/2/3, Q/E, mouse wheel), dynamic spread and bloom, recoil, damage falloff, head/limb multipliers. A procedural view model with sway, bob, kick, reload and equip animation; tracers, impacts and procedural audio.
- **Health and damage**: `IDamageable`, `DamageInfo`, region hitboxes, server-authoritative `HealthSystem` with regeneration and spawn protection.
- **HUD**: health, ammo, fire mode, weapon slots, reload bar, dynamic crosshair (5 styles, player colour), hit and kill markers, damage-direction arcs, kill feed, match timer, team scores, objective status, world markers, location name, death screen, scoreboard. Themed by `HUDTheme`.
- **Map system**: a data-driven `MapBlueprint` generates a 1 km sculpted and painted terrain with a 560 m playable valley:
  - team spawn bases
  - three capture objectives
  - two CQB compounds with rooms, doors, windows and roofs
  - three sniper perches with ramps and drop-down NavMesh links
  - four traversal corridors (canal, main street, rail cut, midline road)
  - scattered cover, rocks, boundaries, spawn points, patrol routes and auto-generated cover points
- **Performance**:
  - LOD groups on every kit piece, with procedural LOD rock meshes
  - static batching flags, occluder/occludee flags and an occlusion area
  - per-layer camera cull distances
  - CullingGroup-based detail sector streaming
  - real-time-only lighting (no lightmap rebakes), throttled time-of-day GI updates
  - AI level of detail
- **Advanced bot AI** (`AdvancedBotAI`): a priority-based FSM with these states: Patrol, Investigate, Engage, TakeCover, Reload, Flank, Search and Dead.
  - Vision cone raycasting with a gradual awareness meter.
  - Hearing of footsteps, gunfire and impacts, muffled by walls.
  - Suppression from near misses.
  - Cover search with protection raycasts and squad reservations.
  - Flanking and staggered reloads.
  - Squads with shared intel, objectives and formations.
  - Human-like aim: settle time, error cone, tracking speed, reaction time.
  - Four difficulty profiles: Recruit, Regular, Veteran, Elite.
- **Networking**:
  - Server-authoritative movement with client-side prediction and reconciliation.
  - Snapshot interpolation for remote players.
  - Hitscan lag compensation that rewinds hitboxes.
  - Deterministic seeded spread, validated on the server.
  - NetworkVariables for health, match state, scores and zones; RPCs for input, shots, FX, damage, reload and switching.
  - Connection approval (version, capacity, names) and a dedicated-server command line.
  - Humans and bots share one match, with team balancing and bot back-fill.

## Quick start

1. Install **Unity 6 LTS** (6000.0.x or newer 6000.x) through Unity Hub. For dedicated servers, include the *Linux/Windows Dedicated Server Build Support* modules.
2. Clone this repository and open the folder in Unity Hub (**Add project from disk**). Packages resolve from `Packages/manifest.json`.
3. If Unity asks to **enable the new Input System backends**, click **Yes** (the editor restarts).
4. Run **`FPS > Build Everything`** from the menu bar. This takes about 1–3 minutes, mostly the NavMesh bake. Restart the editor if the dialog asks you to.
5. Open `Assets/_Project/Scenes/Bootstrap.unity` and press **Play**. Click **HOST GAME** to play against bots, or **JOIN GAME** with the host's IP.
   - Shortcut: open `Battlefield.unity` and press Play to start a local host with bots immediately.

Headless build of the whole project (CI-friendly):

```bash
Unity -batchmode -quit -projectPath . \
  -executeMethod FPS.EditorTools.FPSProjectBuilder.BuildAllBatch -logFile -
```

The full step-by-step guide, with terminal commands, package details, component wiring tables, the networking model, AI design and extension recipes, is in **[Docs/IMPLEMENTATION_GUIDE.md](Docs/IMPLEMENTATION_GUIDE.md)**.

## Controls

| Action | Keyboard / Mouse | Gamepad |
|---|---|---|
| Move / Look | WASD / Mouse | Left stick / Right stick |
| Sprint | Left Shift | Left stick press |
| Jump | Space | South (A) |
| Crouch | Left Ctrl or C | East (B) |
| Fire / Aim | LMB / RMB | RT / LT |
| Reload | R | West (X) |
| Switch weapon | 1-3, Q / E, mouse wheel | North (Y) |
| Scoreboard | Tab | Select / View |
| Menu / settings | Esc | Start / Menu |
